    Cheat sheet

    IonTestPositive resultIonic equation
    Cl−Dilute HNO3, then AgNO3(aq)white precipitateAg+(aq) + Cl−(aq) → AgCl(s)
    Br−Dilute HNO3, then AgNO3(aq)cream precipitateAg+(aq) + Br−(aq) → AgBr(s)
    I−Dilute HNO3, then AgNO3(aq)yellow precipitateAg+(aq) + I−(aq) → AgI(s)
    SO42−Dilute HCl, then BaCl2(aq)white precipitateBa2+(aq) + SO42−(aq) → BaSO4(s)
    CO32−Dilute HCl; test the gas with limewaterfizzing; limewater turns milkyCO32−(aq) + 2H+(aq) → H2O(l) + CO2(g)

    Exam tips

    • Halide colours deepen down the group: white → cream → yellow.
    • Acidify the silver test with nitric acid, never HCl. Acidify the barium test with HCl.
    • Say “limewater turns milky (cloudy)” and name the gas “carbon dioxide”.
